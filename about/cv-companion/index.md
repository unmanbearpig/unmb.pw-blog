# I build and operate backend systems that carry real product responsibility.

I am a senior software engineer with more than 15 years of professional experience. Ruby on Rails and PostgreSQL are my deepest commercial tools; current work also uses Go and Python for public products, data pipelines, extraction and evaluated AI systems.

My strongest work combines implementation with judgment. I built and operate HostelPunk across multi-source ingestion, entity resolution, 235 versioned analysis signals, product code and infrastructure. For Vestuario Antiguo, I created the complete visual identity and logo, designed the interface, built the Rails application and continue to manage production. Earlier work includes an eight-year Rails client engagement and roughly 10x response-time improvements on a marketplace serving more than four million monthly users.

I use coding agents for leverage, but I retain the engineering responsibility: defining the work, choosing the architecture, reviewing the output, testing it and operating the result.

I am based in Santiago, Chile, fluent in English and available for senior backend or product-engineering roles with Americas time-zone overlap.
